# UI UX Review

Use when reviewing a user-facing screen or interaction for usability, clarity, accessibility, or consistency.

## Review

1. Identify the user's goal and walk through the normal flow, including loading, empty, success, error, and recovery states that apply.
2. Check whether labels, instructions, defaults, and feedback make the next action and system state clear.
3. Review keyboard access, focus order and visibility, semantic controls, readable contrast, and accessible names for interactive elements.
4. Check validation timing and placement, preservation of entered data, prevention of accidental destructive actions, and clear recovery from errors.
5. Compare navigation and interaction patterns with nearby screens. Consider narrow layouts and long or localized content where relevant.
6. Distinguish a usability defect from a stylistic preference and tie each finding to a specific user task.

Report the affected flow, user impact, evidence, and a focused improvement. Do not redesign unrelated parts of the interface.
